# scorebook — 紙のスコアブックを撮るだけで、試合結果と打順ごとの成績

手書きの野球スコアブック 1 枚の写真から、回ごとの得点と打順ごとの成績（打席・打数・安打・四死球・三振・得点・打率など）を出します。
Built with Claude: Japan 2026 の作品です。

## しくみ
1. **格子を見つける**（OpenCV、`cv/`）：写真の傾きを直し、回の列と打順の行を見つけて、列ごとに切り出す。
2. **列ごとに Claude に聞く**（`scorebook/read.py`、`scorebook/prompts/facts_v2.txt`）：各マスに打席があるか、結果（アウト／単打…／四球／死球／失策）、三振か、アウトのローマ数字、得点したか、残塁か。1 列 1 回、1 枚 13 回。
3. **用紙の上の得点表も読む**（`scorebook/prompts/header.txt`、1 回）。
4. **組み立てる**（`scorebook/game.py`）：打順の並び → 回の割り当て → 成績。
5. **画面に出す**（`scorebook/web.py`）：マスから計算した得点表と用紙の得点表を並べて違う回に色を付け、読みが割れたマスを「確認してほしいところ」として出す。選手名は読まず、格子の画像も名前の欄を含めない。

## 測った成績（開発用の 33 枚・同じ印刷の用紙・1 チームの試合・Claude Code cloud で測定・2026-10-21）
| 項目 | 一致 |
| --- | --- |
| イニングごとの得点表（全部一致） | 25/33 |
| チームの得点 | 27/33 |
| 打席の結果（マスごと） | 859/941 |
| 得点したか（マスごと） | 913/923 |
| 三振 | 正解 133 のうち 132 を当て、誤りは 4 |
| 打順ごとの成績行（PA AB H BB HBP R が全部一致） | 266/321 |

- 同じ写真をもう一度読むと、得点表は 1〜2 試合ぶん動きます（25 → 26）。
- 2 回の読みが割れたマスの誤りは 61%、割れなかったマスは 6%。
- 計算した得点表が外れた 8 試合は、8 試合とも用紙の得点表と違っていました。用紙側も、タイブレークや書きかけで違うことがあります（7/25）。
- 限界：1 種類の印刷用紙・1 チームの記録者たちの書き方でしか測っていません。選手名・途中交代は扱いません。11 人目の打者の書き方、インクの無い回には未対応です。

## 動かし方
```
pip install numpy==2.4.6 opencv-python-headless==5.0.0.93
export SCOREBOOK_API_KEY=...   # Anthropic API キー
python -m scorebook.web        # http://127.0.0.1:8000/ で写真を上げる（1 枚 14 回の呼び出し・約 20 秒）
python -m scorebook <写真> --sheet <名前> --api   # コマンドラインで 1 枚
```
モデルは `claude-opus-5-5`（adaptive thinking）。返答は `runs/api-cache/` に写真の md5 で保存し、同じ写真は二度と呼びません。
