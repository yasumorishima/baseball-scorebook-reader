# scorebook — 紙のスコアブックを撮るだけで、試合結果と打順ごとの成績

手書きの野球スコアブック 1 枚の写真から、回ごとの得点と打順ごとの成績（打席・打数・安打・四死球・三振・得点・打率など）を出します。
Built with Claude: Japan 2026 の作品です。

## しくみ
1. **格子を見つける**（OpenCV、`cv/`）：写真の傾きを直し、回の列と打順の行を見つけて、列ごとに切り出す。
2. **列ごとに Claude に聞く**（`scorebook/read.py`、`scorebook/prompts/facts_v2.txt`・`corners.txt`）：各マスに打席があるか、結果（アウト／単打…／四球／死球／失策）、三振か、アウトのローマ数字、得点したか、残塁か。もう 1 つの質問で塁の角の印（どの打者のときに進んだか、盗塁の S）を読み、打点と盗塁を出す。1 列 2 回、1 枚 26 回。
3. **用紙の上の得点表**（`scorebook/prompts/header.txt`、1 回）と、**名前の欄**（`scorebook/prompts/lineup.txt`、1 回。打順ごとの選手と交代した回）も読む。名前は入力欄の手がかりとして出すだけで、確かめて入れるのは利用者。
4. **組み立てる**（`scorebook/game.py`）：打順の並び → 回の割り当て → 成績。
5. **画面に出す**（`scorebook/web.py`）：マスから計算した得点表と用紙の得点表を並べて違う回に色を付け、「用紙で確かめるマス」を出す。「2 回読む」では 2 回目に「確かでない欄は unsure と書く」質問（`scorebook/prompts/facts_v2_unsure.txt`）を使い、1 回目と割れたマスと、2 回目が確かでないとしたマスを出す。打順ごとの成績（打点・盗塁・三振を含む）は CSV で保存できる。格子の画像は名前の欄を含めない。

## 測った成績（開発用の 33 枚・同じ印刷の用紙・1 チームの試合・Claude Code cloud で測定・2026-10-21）
| 項目 | 一致 |
| --- | --- |
| イニングごとの得点表（全部一致） | 25/33 |
| チームの得点 | 27/33 |
| 打席の結果（マスごと） | 859/941 |
| 得点したか（マスごと） | 913/923 |
| 三振 | 正解 133 のうち 132 を当て、誤りは 4 |
| 打順ごとの成績行（PA AB H BB HBP R が全部一致） | 266/321 |
| チームの記録係がサイトに登録した成績との一致（18 試合、打順の行の 8 項目が全部一致） | 129/176 |
| 打点・盗塁（同じ 18 試合、打順の行で一致） | 92%・93% |

- 同じ写真をもう一度読むと、得点表は 1〜2 試合ぶん動きます（25 → 26）。
- 用紙で確かめるマス（2026-11-23）：33 枚で、1 回目の読みの誤り 92 マスのうち 77 に印が付いた（印は 1 枚あたり約 7 マス）。同じ質問で 2 回読んで割れたマスだけを出す前のやり方では、印 46 で 28。印の無いマスも誤りはありえます。
- 計算した得点表が外れた 8 試合は、8 試合とも用紙の得点表と違っていました。用紙側も、タイブレークや書きかけで違うことがあります（7/25）。
- 限界：1 種類の印刷用紙・1 チームの記録者たちの書き方でしか測っていません。選手名・途中交代は扱いません。11 人目の打者の書き方、インクの無い回には未対応です。

## 生成 AI を使わずに読む部品（`cv/`）
OpenCV と NumPy だけでマスの中の印を読む、研究開発の部品も置いています（格子の検出・手書きの取り出し・アウトの数字・塁の区画の番号・野球の決まりと合わせて解くソルバー）。正解データと画像は含まないので、そのままでは動きません。説明は [`cv/README.md`](cv/README.md)。

## 動かし方
```
pip install numpy==2.4.6 opencv-python-headless==5.0.0.93
export SCOREBOOK_API_KEY=...   # Anthropic API キー
python -m scorebook.web        # http://127.0.0.1:8765/ で写真を上げる（1 枚 28 回の呼び出し・約 20 秒）
python -m scorebook <写真> --sheet <名前> --api   # コマンドラインで 1 枚
```
モデルは `claude-opus-5-5`（adaptive thinking）。返答は `runs/api-cache/` に写真の md5 で保存し、同じ写真は二度と呼びません。
